Hologram shader

A three.js material that turns any mesh into a projected volume of light: a translucent centre, a cyan fresnel rim, a lattice of dots for the surface, and bursts of interference that jitter the vertices and split the colour. The meshes are two real brain surfaces and nine real cells from the MICrONS volume. Drag to turn one, scroll to zoom. Source in js/holo-material.js; the rest of the library is on the main page.

Use it

Three calls. The bounds are read from the object after it is placed, so apply the material last.

import { makeHologramMaterial, applyHologram, tickHologram }
  from "./js/holo-material.js";

const holo = makeHologramMaterial({ color: "#7EE0FF" });
applyHologram(mesh, holo);          // after mesh is positioned and scaled
// each frame:
tickHologram(holo, timeInSeconds);
